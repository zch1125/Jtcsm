## 一、全局规范

### 1.1 鉴权方式

JWT Bearer Token：
```
Authorization: Bearer {token}
```

### 1.2 统一响应体

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 1.3 错误码定义

| code | 含义 | 触发场景 |
|------|------|----------|
| 200 | 成功 | — |
| 401 | 未登录 | Token 缺失 / 过期 / 无效 |
| 402 | 需要会员 | 普通用户访问 VIP 功能 |
| 403 | 无权限 | 越权操作 |
| 404 | 资源不存在 | 查询实体不存在 |
| 429 | 请求过于频繁 | 接口限流触发 |
| 500 | 服务器错误 | 未捕获异常 |

### 1.4 分页规范

**请求参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码，从 1 开始 |
| size | int | 20 | 每页条数 |

**分页响应格式：**

```json
{
  "records": [],
  "total": 100,
  "page": 1,
  "size": 20
}
```

### 3.3 AI 模块

#### POST `/api/v1/ai/generate` — AI 生成菜谱

```
Request:
{
  "mode": "ingredients",
  "ingredients": ["鸡蛋", "番茄", "葱"],
  "conditions": "少油少盐"
}

Response (200):
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 42,
    "recipes": [
      {
        "name": "番茄炒蛋",
        "cuisine": "家常",
        "difficulty": "简单",
        "cookTime": 15,
        "ingredients": [
          { "name": "番茄", "amount": "2个" },
          { "name": "鸡蛋", "amount": "3个" }
        ],
        "steps": [
          { "stepNo": 1, "content": "..." },
          { "stepNo": 2, "content": "..." }
        ]
      }
    ],
    "fromCache": false
  }
}
```

**生成模式说明：**

| mode | 参数 | 说明 |
|------|------|------|
| `ingredients` | ingredients (List) | 根据食材生成可行菜谱 |
| `name` | name (String) | 根据菜名补全用料与步骤 |
| `creative` | cuisineA + cuisineB | 融合两种菜系生成创意菜谱 |

**限流与缓存：**
- 普通用户 3 次/天，VIP 100 次/天
- 相同输入 24h 内走 Redis 缓存
- API 不可用时返回兜底菜谱
